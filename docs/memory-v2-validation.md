# Memory v2 验证报告

日期：2026-11-06；发布包：SV_SOUL 1.1.0。

## 代码及独立测试

- Release 构建通过，39 项核心检查在 DSW Linux 和 Windows home 的 .NET 6 运行时均通过。
- 测试直接编译生产 NPCAgent、存储和检索代码；只有 SMAPI 日志接口被替身替换。游戏状态以不可变 JSON 快照输入，无需启动游戏。HTTP 采用可控处理器，模拟慢提取、鉴权失败、伪造证据等。
- 覆盖 OpenAI/Anthropic 请求格式，8轮上下文上限，婚姻阶段提示，未知日期约束，长人设预算，后台提取不阻塞回复，证据 ID 验证，失败请求不落盘，对话时间/ID稳定，存档与 NPC 隔离，导出快照与回滚，历史有效期，记忆清除，取消旧会话，中英文词汇召回，跨季节“昨天”，季节枚举大小写，以及游戏时间优先的近期排序。
- 原始输出：[DSW](../artifacts/tests/memory-v2-core.txt)、[Windows](../artifacts/tests/memory-v2-windows.txt)、[构建](../artifacts/tests/memory-v2-build.txt)。检索性能是100次热调用的 P95，数据量10,000条；不包含首次索引构建、完整存档序列化或网络模型时间。
- 小型中英文召回用例全部通过。尚未建立足够规模的自然语言标注集，因此不宣称总体 Recall@8 已达到90%。

## Mac 游戏实测

环境：Stardew Valley 1.6.15 / SMAPI 4.5.2。

1. 1.1.0、Lucene.NET、J2N、Microsoft.Extensions 成功加载；赠礼观察补丁没有报告安装失败。
2. 通过本地测试请求传送到 Abigail 并打开聊天。
3. 快照读到 Married、14心、配偶 Abigail、荔枝农场、一个孩子和婚礼日期 Year 4, fall 8, Monday。主线程快照采样约0.74–1.34 ms；这不是完整P95测量。
4. 用户测试问题：“我们现在是什么关系？平时一起住在哪里？你还记得婚礼日期吗？”
5. 实际回复：“我们是夫妻呀！平时一起住在荔枝农场的家里。我们的婚礼是在第四年秋天的8号，星期一。”
6. 用户测试偏好：“记住：我喜欢钓鱼，最喜欢紫水晶。”回复先返回；约30秒后进行后台提取，读回得到两条 PlayerStatement，均引用对应玩家消息 ID。前面的关系提问和 NPC 回答没有被再写成玩家经历。
7. 游戏运行时发现季节枚举会输出数字/首字母大写；最终包已统一季节小写字符串，补充枚举兼容回归用例。最终包也加入既有主题键供后续更正复用。

截图：[已婚关系与住所](../artifacts/screenshots/memory-v2-married.png)。诊断快照在本地 artifacts/tests/memory-v2-mac-context.json，无 API 密钥，属于测试数据，不作为运行时记忆来源。
