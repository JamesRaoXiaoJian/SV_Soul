# SV_SOUL - Release

AI-Powered Chat NPCs for Stardew Valley.

## 安装

1. 安装 [SMAPI](https://smapi.io/) 4.0.0+
2. 将此文件夹放入 `Stardew Valley/Mods/SV_SOUL/`
3. 启动游戏让 SMAPI 生成配置文件
4. 编辑 `config.json`，填入你的 API Key
5. 进入游戏，靠近 NPC 按交互键开始聊天

## 配置

编辑 `config.json`：

```json
{
  "ApiKey": "你的API密钥",
  "Model": "claude-sonnet-4-20250514"
}
```

更多配置项和自定义 NPC 教程请访问 [源代码仓库](https://github.com/JamesRaoXiaoJian/SV_Soul)。
