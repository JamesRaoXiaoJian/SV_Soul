# 五角色档案与动态情境（1.3.0）

范围：当前内置的 Abigail、Shane、Sebastian、Elliott、Haley，不代表已支持全游戏所有 NPC。新增 NPC 仍需自己的角色 JSON 和 EnabledNPCs 配置。

## 固定与动态数据

| 类别 | 内容 | 更新方式 |
|---|---|---|
| 固定角色写作 | 行为倾向、语气、历史背景、语气示例 | 角色 JSON；修改后重启加载 |
| 当前关系与家庭 | 交往/订婚/婚姻/离婚/室友、住所、孩子 | 每次回复重新捕获；长期关系事实按原有事件与时间采样观察 |
| 当前情境 | 日期时刻、生日、节日、天气、心数、当天赠礼 | 每次回复新快照；开场也读取新快照 |
| 相处经历 | 玩家偏好、已观察赠礼、主观理解 | 现有带来源的记忆流程 |
| 未验证剧情 | 小说是否出版、就业/治疗进展等 | 未接入可靠事件之前标为未知，不从旧人设推断 |

五位角色分别有行为档案、至少11组语气样例、婚姻阶段及生日/时段等情境提示。共用事实约束与对话意图，角色反应各自编写，不复制 Abigail 的性格。高好感不等于恋爱，低好感也不抹去已有婚姻和共同历史。

情境提示是写作方向，不是已执行的动作或已测得的心理状态；不会自动改变原版好感度、职业或日程。长期情绪模拟仍未加入。

## 验证

71项独立测试通过，Release构建通过（保留既有CS9057分析器版本警告）。15条真实API输出检查了五位角色的安慰、自己的打算和离婚状态；发现低好感被表述成“不熟悉”的风险后，调整情境投影，并对五位角色的离婚问题另做5次复测。最初5条复测均遇到TLS连接失败，未得到回复；随后显式使用已有本地代理复试5次。共25次请求尝试；小样本，不是盲评结论。

下一节保留首轮中“仍不算熟”等表述，以展示实际发现；复测列于末尾。未在游戏内逐一验收所有生日、天气、赠礼场景。原始结果见 artifacts/tests/npc-profile-responses.json、npc-divorce-responses.json，单元输出见 npc-profiles-core.txt。
