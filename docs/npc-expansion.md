# NPC 扩展：十二位可恋爱角色（1.4.0）

适配当前 Stardew Valley 1.6.15。新增 Alex、Emily、Harvey、Leah、Maru、Penny、Sam，已有五位档案保留。本版没有扩展到所有村民，也没有引入尚未适配的未来游戏版本角色。

## 新角色方向

| NPC | 表达与关注点 |
|---|---|
| Alex | 直接、自信，重视训练与被认可，也允许脆弱 |
| Emily | 温暖、有想象力，偏好色彩、制作与自然；直觉不冒充事实 |
| Harvey | 认真温和，有自己的航空/无线电爱好；闲聊不变成诊断 |
| Leah | 坦率、独立，重视艺术和自己的选择 |
| Maru | 好奇、清楚、敢于试验；关心别人不只提供解决方案 |
| Penny | 轻柔认真、有边界，关注阅读、教学与安稳生活 |
| Sam | 轻松直爽，重视音乐和身边的人，知道何时收起玩笑 |

每位角色包含11组新写的语气样例、独立行为档案、关系阶段提示和动态情境开场。示例不是原版对话引用，也不会写入历史记忆。背景参考如下角色资料页，当前住所、家庭、生日、关系与赠礼信息仍优先读取游戏状态。

人物参考：[Alex](https://stardewvalleywiki.com/Alex), [Emily](https://stardewvalleywiki.com/Emily), [Harvey](https://stardewvalleywiki.com/Harvey), [Leah](https://stardewvalleywiki.com/Leah), [Maru](https://stardewvalleywiki.com/Maru), [Penny](https://stardewvalleywiki.com/Penny), [Sam](https://stardewvalleywiki.com/Sam)。

## 配置与更新

新安装默认启用十二位角色。已有安装不会被代码强行重置 EnabledNPCs；本次 Mac 部署已备份旧配置，并在原列表中追加七位新角色。API密钥、模型和记忆保留。其他机器手动升级时，需要将新名字加入 EnabledNPCs。

开场与每轮回复使用最新快照；静态档案修改需重启。婚后居住、离婚、生日、节日、天气等沿用共享机制。没有可靠来源的剧情结果、演出、工作安排、作品出版和房屋变化不会从背景里自动推断。

## 验证

119项独立检查通过；包含十二位档案文件匹配、关系切换、婚后示例隔离和动态开场；Release构建通过，保留已有CS9057分析器版本警告。原始输出：artifacts/tests/npc-expansion-core.txt。

下面是对新增七位角色各一次真实API请求的结果（合成场景，不读写玩家存档）。单次输出不是全面角色质量验收；未逐一进行游戏内交互测试。

### Alex
你有什么自己想做的事？

我想继续训练，看看自己能走多远。也想多陪陪爷爷奶奶，和你一起把日子过好。

有时候我还挺在意别人怎么看我，但我想学着更相信自己的判断。

### Emily
你有什么自己想做的事？

我想试着缝一件颜色大胆一点的衣服，不用顾虑它够不够时髦，只要穿起来让我开心就好。也想找个时间随着喜欢的音乐跳舞。

### Harvey
你有什么自己想做的事？

我想找个安静的晚上，泡杯咖啡，听听无线电。也想再看看航空方面的资料，总有些东西能让我着迷。

### Leah
你有什么自己想做的事？

我想找块形状有意思的木头，雕一件小东西。还没想好具体是什么，先看看木头的纹理再决定吧。

### Maru
你有什么自己想做的事？

我想找个晴朗的夜晚观察星空，看看能不能认出以前没注意过的星座。还有一个小装置的想法，也想慢慢琢磨，看看能不能做出来。

### Penny
你有什么自己想做的事？

我想找本没读过的书，慢慢读完。也想多花点心思，给 Jas 和 Vincent 准备些有趣的课程。

今晚的话，我只想安静地和你待一会儿。

### Sam
你有什么自己想做的事？

我想写点新的音乐，试试跟朋友一起把它变成一首完整的歌。也想找时间练练滑板，有个动作我一直想试，但还没练成。

成功回复：7/7。
